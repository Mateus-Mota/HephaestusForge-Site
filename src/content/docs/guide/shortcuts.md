title: Keyboard Shortcuts
description: Quick reference of global, GDD editor, and Kanban keyboard shortcuts inside HephaestusForge.
---

Master these shortcuts to move between your GDD, Kanban board, 37 Studios, and Godot 4 without leaving the keyboard.

## Global Navigation & Engine

| Shortcut | Action |
| :--- | :--- |
| `Ctrl + K` | Open the **Command Palette** (jump to modules, docs, tasks, studios, and Kenney tools) |
| `F5` | **Play** — launch the active project directly in Godot 4 |
| `Ctrl + ,` | Open **Project & Workbench Settings** |
| `Escape` | Close active modal, studio dialog, or Command Palette |
| `?` *(top bar)* | Open contextual in-app help for the active screen |

:::tip[Command Palette is the fastest way into any Studio]
Instead of scrolling through the 37 studios, press `Ctrl + K` and type a few letters like `shader`, `hud`, `sfx`, or `parallax` to open the studio immediately.
:::

## GDD Editor (CodeMirror 6)

| Shortcut | Action |
| :--- | :--- |
| `Ctrl + S` | Save active Markdown document atomically (ETag / SHA-256) |
| `Alt + ←` | Navigate back in document history |
| `Alt + →` | Navigate forward in document history |
| `[[` | Trigger `[[WikiLink]]` autocomplete across your GDD and ADRs |
| `Ctrl + F` | Find and replace inside the current document |

## Kanban Board

| Shortcut | Action |
| :--- | :--- |
| `Alt + ←` | Move focused task card to the previous lane |
| `Alt + →` | Move focused task card to the next lane |
| Pointer drag | Click and hold on any card body (outside action buttons) to drag across lanes |

:::note[Customizable Sidebar]
Prefer keyboard + minimal UI? Open **More (`⋯`)** at the bottom-left to unpin modules you rarely click and keep only your daily essentials visible — see [Workspace & Customizable Sidebar](/guide/workspace-and-tools/).
:::
