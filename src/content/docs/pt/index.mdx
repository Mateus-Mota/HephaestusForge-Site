## O que tem dentro do HephaestusForge

<CardGrid stagger>
  <Card title="100% File-over-App (Zero Lock-in)" icon="document">
    Todo GDD, tarefa do Kanban, ADR, fluxo narrativo e skill de IA vive em arquivos reais `.md` e `.json` dentro do repositório Git do seu jogo. Sem banco de dados proprietário.
  </Card>
  <Card title="37 Estúdios Internos + Godot 4" icon="puzzle">
    Animação de Sprites, Shader VFX 2D, HUD, Tilemap Collision, Sintetizador SFX, Frame Data de Combate, Diálogos, Zonas de Câmera e Parallax 2D — exportando `.tres`, `.tscn`, `.gd` e `.gdshader` direto no projeto.
  </Card>
  <Card title="Kanban ligado ao Git e Play (F5)" icon="approve-check-circle">
    Arraste cards entre colunas com arquivos JSON limpos (LexoRank), sugestão de branch por tarefa e execução imediata do jogo com `F5`.
  </Card>
  <Card title="Catálogo de Assets & Starter Packs Kenney" icon="open-book">
    Aponte para sua biblioteca local de pacotes `.zip` CC0 do Kenney para iniciar projetos Godot 2D já jogáveis e auditar sprites, áudio e malhas 3D com `.forge/asset_spec.json`.
  </Card>
  <Card title="Workspace Customizável & Skills de IA" icon="setting">
    Fixe, desafixe e reordene qualquer módulo da barra lateral, use o Prompt Studio com contexto vivo e explore o Radar de Ferramentas Públicas.
  </Card>
  <Card title="Core Nativo em Rust (Tauri v2)" icon="rocket">
    Instalador leve (~10 MiB), boot instantâneo, escrita atômica com ETag/SHA-256 e zero portas TCP abertas na máquina.
  </Card>
</CardGrid>
