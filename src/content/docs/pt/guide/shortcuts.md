Domine estes atalhos para alternar entre seu GDD, quadro Kanban, os 37 Estúdios e o Godot 4 sem tirar as mãos do teclado.

## Navegação Global & Engine

| Atalho | Ação |
| :--- | :--- |
| `Ctrl + K` | Abre a **Paleta de Comandos** (módulos, documentos, tarefas, estúdios e geradores Kenney) |
| `F5` | **Play** — executa o projeto ativo diretamente no Godot 4 |
| `Ctrl + ,` | Abre **Configurações do Projeto & Estação de Trabalho** |
| `Escape` | Fecha modal ativo, diálogo de estúdio ou Paleta de Comandos |
| `?` *(barra superior)* | Abre a ajuda contextual da tela atual |

:::tip[A Paleta de Comandos é o caminho mais rápido para qualquer Estúdio]
Em vez de rolar pelos 37 estúdios, pressione `Ctrl + K` e digite poucas letras como `shader`, `hud`, `sfx` ou `parallax` para abrir a ferramenta na hora.
:::

## Editor de GDD (CodeMirror 6)

| Atalho | Ação |
| :--- | :--- |
| `Ctrl + S` | Salva o documento Markdown atomicamente (ETag / SHA-256) |
| `Alt + ←` | Volta no histórico de documentos visitados |
| `Alt + →` | Avança no histórico de documentos visitados |
| `[[` | Abre o autocompletar de `[[WikiLinks]]` entre GDDs e ADRs |
| `Ctrl + F` | Localiza e substitui texto no documento atual |

## Quadro Kanban

| Atalho | Ação |
| :--- | :--- |
| `Alt + ←` | Move o card de tarefa focado para a coluna anterior |
| `Alt + →` | Move o card de tarefa focado para a próxima coluna |
| Arraste manual | Clique e segure no corpo do card (fora dos botões de ação) para arrastar entre raias |

:::note[Barra Lateral Customizável]
Prefere teclado + interface limpa? Clique em **Mais (`⋯`)** no canto inferior esquerdo para desafixar módulos que você pouco clica e deixar visíveis só os essenciais do dia a dia — veja [Workspace & Barra Customizável](/pt/guide/workspace-and-tools/).
:::
