:::note[Aviso do Windows SmartScreen]
Como as primeiras versões indie ainda não possuem certificado comercial EV de assinatura de código, o Windows SmartScreen pode exibir *"O Windows protegeu o computador"* na primeira execução. Clique em **Mais informações → Executar assim mesmo** se você baixou o instalador diretamente desta página oficial ou das Releases no GitHub, e valide o hash SHA-256 acima se desejar.
:::

## Requisitos de Sistema
- **Windows 10 ou Windows 11 (64-bit)**
- **Microsoft Edge WebView2 Runtime** (já vem pré-instalado no Windows 11)
- **Godot 4.x** *(opcional — necessário apenas para executar `Play F5` direto da Forja)*

:::tip[Link curto para compartilhar]
Você pode usar o endereço curto `/download` para redirecionar diretamente para o instalador `.exe` mais recente do Windows.
:::
