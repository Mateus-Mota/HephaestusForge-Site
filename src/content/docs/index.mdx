## What's Inside HephaestusForge

<CardGrid stagger>
  <Card title="100% File-over-App (Zero Lock-in)" icon="document">
    Every GDD document, Kanban task, ADR, dialogue flow, and AI skill lives in plain `.md` and `.json` files inside your game's Git repository. No proprietary database.
  </Card>
  <Card title="37 Built-in Studios + Godot 4" icon="puzzle">
    Sprite Animation, 2D Shader VFX, HUD Layout, Tilemap Collision, SFX Synthesizer, Combat Frame Data, Dialogues, Camera Zones, and 2D Parallax — exporting `.tres`, `.tscn`, `.gd`, and `.gdshader` straight to your project.
  </Card>
  <Card title="Kanban Linked to Git & Play (F5)" icon="approve-check-circle">
    Drag-and-drop task lanes backed by flat JSON files (LexoRank), per-task Git branch suggestions, and instant `F5` engine launch right from any task.
  </Card>
  <Card title="Asset Catalog & Kenney Starter Packs" icon="open-book">
    Point to your local CC0 Kenney `.zip` library to bootstrap playable Godot 2D scenes and audit sprites, audio, and 3D meshes against `.forge/asset_spec.json`.
  </Card>
  <Card title="Customizable Workspace & AI Skills" icon="setting">
    Pin, unpin, and reorder every sidebar module, run context-aware AI prompts, and browse the Public Tools Radar without clutter.
  </Card>
  <Card title="Native Rust Core (Tauri v2)" icon="rocket">
    Lightweight ~10 MiB installer, instant startup, atomic ETag/SHA-256 writes, and zero local TCP ports exposed.
  </Card>
</CardGrid>
